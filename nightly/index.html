リズム天国リプラスのパッチ

リズム天国リプラスのパッチは準備中です。
元のリズム天国プラスのパッチは、元のサイトで配布されています。

デバッグ版について

「デバッグ」では以下のような機能が追加されます。
- メインメニューで「リズムゲーム」を選択するときにL+Rを押しながらAボタンを押すとデバッグメニューへ移動
- ゲーム中にL+Rを押している間だけオートモード

デバッグメニューには「セーブエディター」が含まれています。編集はセーブデータのコピーに対して行われ、Lを押しながらSELECTを離した時だけ実際のセーブデータに書き込まれます。SELECTだけで終了すれば、変更は保存されません。
それでも念のため、定期的にセーブデータのバックアップを取っておくことをお勧めします。セーブエディターを使ったセーブデータの破損につきましては責任を負いかねます。

パッチの適用

BPSパッチの適用には以下のサイトの使用をおすすめします。
- BPS PATCHER (BPSパッチ適用ツール) - SAVE EDITOR
- Rom Patcher JS
